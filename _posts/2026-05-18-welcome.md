White Ravens is starting a blog.

Until now, updates were scattered across Discord threads and Mastodon
posts. We wanted a single, persistent place for longer-form writing —
engineering deep-dives, release notes, and community spotlights.

This site is built with Jekyll, hosted on GitHub Pages, and kept minimal
on purpose: dark mode by default, monospace code blocks, and no tracking
scripts. If you want to contribute, open a PR; the repo is public and the
license is MIT.

Expect posts on:

- How we self-host services without Kubernetes
- Privacy-first patterns in modern web apps
- Release changelogs and migration guides
- Community interviews and spotlights

Thanks for reading. The first real post is coming soon.
